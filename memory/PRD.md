# Vapor — PRD

## Исходная задача
Главная страница онлайн-казино в стиле платформы Steam. Сначала только набросок дизайна: шапка, основа (div), подвал. Структура шапки/фона/подвала по мотивам upgrader.com, цвета и иконки Steam. Режимы — позже, по указанию пользователя.

## Архитектура
- Только фронтенд (React, CSS в `App.css`). Бэкенд не используется.
- `components/Header.jsx`, `components/Footer.jsx`, `components/Logo.jsx`, `public/favicon.svg`.

## Сделано (июнь 2026)
- Шапка: логотип, верхнее меню, новости, уведомления, баланс + пополнение, профиль (аватар, имя), вкладки навигации.
- Фон: сетка + свечение в цветах Steam.
- Основа: пустой блок-заглушка.
- Подвал: логотип, дисклеймер, 3 колонки ссылок, копирайт, фиксированная нижняя панель.
- Проверено testing agent: фронтенд 100%.

## Обновление 2 (июнь 2026)
- Название изменено на Steamgrader, новый логотип и favicon.
- Вкладка «Режимы»: карточки Кейсы, Апгрейдер, Мины (пометка «Скоро», сами игры не сделаны).
- Вкладка «Инвентарь»: пустая сетка слотов.
- Баланс: переключатель валюты ₽ / ₸ / ₴ (без пересчёта, баланс-образец 0,00).
- Иконки справа в шапке приближены к клиенту Steam.
- Проверено скриншотами, testing agent на этом шаге не запускался.

## Обновление 3 (июнь 2026) — настоящая авторизация Steam
- Удалён фейковый профиль «Гомик» и самодельная форма ввода логина/пароля.
- Реальный вход через Steam OpenID 2.0: `/api/auth/steam` → официальный steamcommunity.com → `/api/auth/steam/callback` (проверка через check_authentication), ник и аватар через Steam Web API (STEAM_API_KEY), JWT в HttpOnly cookie `session`.
- `/api/auth/me`, `/api/auth/logout`. Фронт: AuthContext, в шапке только кнопка «Войти» до входа; после входа — аватар, ник и меню «Выйти».
- Протестировано testing agent: backend 100%, frontend 100%. Полный успешный вход требует реального Steam-аккаунта с 2FA — проверяется вручную.

## Обновление 4 (июнь 2026)
- Верхнее меню: Политика конфиденциальности, Пользовательское соглашение, Честная игра, Поддержка (открывают пустые разделы, текстов документов нет).
- Блок профиля: квадратный аватар Steam в голубой рамке «в сети», ник цветом Steam, заглушка «?» если аватара нет.
- Счётчик «В сети»: реальный, POST /api/online/ping каждые 20 с, коллекция presence (TTL), считается активность за последние 45 с.
- Проверено скриншотами и curl, testing agent на этом шаге не запускался.

## Обновление 5 (июнь 2026)
- Общий чат во вкладке «Сообщество»: только для вошедших через Steam (чтение и отправка), GET/POST /api/chat/messages, опрос раз в 3 с.
- Защита: запрет ссылок, пауза 3 с между сообщениями, запрет повтора за 60 с, запрет 10+ одинаковых символов подряд, лимит 300 символов.
- Окно входа: стекло, текст слева, без левой панели и плашки 18+. Логотип заменён на два шеврона.
- Протестировано testing agent (iteration_4): backend 15/15, frontend 100%. Модерации (удаление, бан, мат-фильтр) нет.
